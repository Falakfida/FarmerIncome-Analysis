# Problem Statement

## Farmer Income Prediction

Farmers' income depends on several factors such as land area, agricultural loans, rainfall, temperature, and other farming-related conditions. Estimating income manually can be difficult due to the interaction of these factors.

This project uses **Machine Learning (Regression)** to predict a farmer's income based on available agricultural, financial, land, and environmental data.

### Objective

- Analyze factors affecting farmer income.
- Train a regression model using historical farmer data.
- Predict income for new farmer records.
- Evaluate the model using appropriate regression metrics.

### Dataset

**Source:** Kaggle  
**Dataset:** Farmer Income Prediction Dataset  
**Link:** https://www.kaggle.com/datasets/manishpatil115/farmer-income-prediction-dataset

### Machine Learning Type

**Supervised Learning → Regression**

**Target:** Farmer Income
